Ce premier projet avait pour but de proposer toutes les fonctionnalités du jeu de la vie, que l'on retrouve dans les deux versions suivante. 
L'idée était de tout coder à la main, avec un simple IDE sans IA intégrée (sauf pour générer les fichiers nécessaires à le faire tourner localement). 
Aucune librairie ni aucun framework n'ont été utilisés, seul vanilla JS en front et node en back-end, le but étant ici d'apprendre les fondements de la programmation full stack. 
Je n'ai pas voulu le terminer, la tâche devenant trop compliquée et chronophage. 
J'ai tout de même réussi à implémenter les fonctionnalités de jeu, inscription/connexion, sauvegarde en base de données, affichage des grilles, like/dislike.
La mise en route de cette application est compliquée, il n'a été mis en dépôt que pour le code.
